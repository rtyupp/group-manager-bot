# بوت إدارة المجموعات 🛡

بوت تيليجرام لإدارة مجموعات العملاء بأوامر **عربية وإنجليزية** — استضافة مجانية 24/7 عبر GitHub Actions.

## المزايا
- 👋 ترحيب تلقائي بالأعضاء الجدد (رسالة مخصصة عبر `/وضع_ترحيب`)
- 🛡 حماية ضد الروابط (تُفعّل بـ `/ضد_روابط on`)
- ⛔ حظر / طرد / كتم / تحذيرات (٣ تحذيرات = حظر تلقائي)
- 🔒 قفل وفتح المجموعة، 📌 تثبيت، 🗑 مسح
- 📜 قواعد المجموعة (`/وضع_قواعد`)
- 💾 الحالة (القواعد، الترحيب، التحذيرات) تُحفظ في `settings.json` داخل المستودع

## الأوامر
| عربي | إنجليزي | الوظيفة |
|------|---------|---------|
| /مساعدة | /help | قائمة الأوامر |
| /قواعد | /rules | عرض القواعد |
| /وضع_قواعد نص | /setrules | وضع القواعد (مشرف) |
| /وضع_ترحيب نص | /setwelcome | رسالة ترحيب مخصصة: `{name}` `{chat}` |
| /قفل /فتح | /lock /unlock | إغلاق/فتح الإرسال |
| /حظر /طرد | /ban /kick | بالرد على رسالة العضو |
| /كتم 30m | /mute | مدة: m دقيقة، h ساعة، d يوم |
| /تحذير /تحذيرات /تصفير | /warn /warns /resetwarns | نظام التحذيرات |
| /تثبيت /مسح | /pin /del | بالرد |
| /ضد_روابط on/off | /antilink | حماية من الروابط |
| /الادمنية /ايدي /بنق | /adminlist /id /ping | معلومات |

## الإعداد في تيليجرام (مرة واحدة)
1. أنشئ المجموعة من تطبيق تيليجرام.
2. أضف البوت إلى المجموعة.
3. اجعله **مشرفاً** بصلاحيات: حذف الرسائل، حظر الأعضاء، دعوة الأعضاء، تثبيت الرسائل.

## التشغيل على GitHub Actions
1. أضف `BOT_TOKEN` في Settings → Secrets and variables → Actions.
2. شغّل السير العمل يدوياً من تبويب Actions (Run workflow) — وبعدها يعمل تلقائياً كل 6 ساعات لمدة 5س45م (تغطية ~96%).

> ⚠️ لا تشغّل البوت محلياً بنفس التوكن أثناء عمل Actions — تيليجرام يسمح بمستهلك واحد فقط لكل توكن (خطأ 409).
